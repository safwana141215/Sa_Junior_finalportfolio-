Neon Runner: Cyberpunk Platformer

Role: Lead Programmer & Designer Engine: Unity 2022 LTS Time: 6 Weeks Team: Solo

A fast-paced 2D platformer set in a neon city. Built for the Junior Programmer Pathway, this game demonstrates player movement physics, enemy AI, and dynamic lighting.

What I Built:

  • Player controller with coyote-time jumping and wall-sliding using Rigidbody2D
  • Enemy AI state machine for patrol, chase, and attack behaviors using C#
  • Neon glow effects with Unity's 2D lights and particle systems
  • Adaptive audio using Unity's Audio Mixer
  • Version control with GitHub feature branches

Reflection:

The first version of my jumping felt "floaty" and playtesters didn't like it. After 3 rounds of feedback, I learned about coyote-time—giving players a tiny window to jump after leaving a platform. This small change made the game feel much more responsive. I also learned that GitHub is essential when I had to rollback a buggy lighting build. This project taught me that games get better through testing, not just planning.

Chrono Cube: Temporal Puzzle Adventure

Role: Systems Designer & Programmer Engine: Unity 2022 LTS Time: 4 Weeks Team: 2-Person Team

A 3D puzzle game where players rewind time to solve environmental challenges. Built for the Creative Core pathway with a partner.

What I Built:

  • Time-reversal system using C# lists to record and playback player/object states
  • 5 puzzle rooms designed through grey-boxing and playtest iteration
  • Clean HUD with temporal energy meter and interaction prompts using Unity UI
  • Baked and real-time lighting to signal puzzle phases to players

Reflection:

Working with a partner taught me how important communication and documentation are. We kept a shared Game Design Document (GDD) and met weekly to align priorities. The hardest bug was objects clipping through walls during rewind—we fixed it by adding predictive collision checks. This experience showed me that great games come from iteration and teamwork, not solo perfection.

Starlight Voyager: Space Exploration

Role: Developer Engine: Unity 2021 Time: 3 Weeks Team: Solo

My first complete Unity project from the Unity Essentials pathway. A simple 3D space exploration experience.

What I Built:

  • Multiple scenes with persistent data using PlayerPrefs and loading transitions
  • Reusable asteroid and collectible prefabs with randomized spawn positions
  • Smooth follow camera using Vector3.Lerp for polished feel

Reflection:

This was my first time using Unity, so everything was new. I learned how Unity's component-based architecture works—attaching scripts to objects to give them behavior. I started using GitHub here, committing after each feature. Looking back, my code organization was messy, but it worked. I keep this project in my portfolio to show my growth mindset and how far I've come since the beginning.
